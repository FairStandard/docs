A filing on Case Detail holds whatever needs to go to the court next, built in structured blocks rather than assembled from scratch each time. <span className="kw">Exhibits</span> number themselves as you add them, so a document keeps the same number from your first draft to the version you file.

1. From Case Detail, open the filing workspace and select **Start a filing**.
2. Choose what you're filing and build it in structured blocks — the workspace supplies the shape, you fill in the content for this case.
3. Add exhibits from the case's existing records rather than uploading anything twice. Each one is numbered automatically as you add it, and stays numbered consistently through revisions.
4. Assemble the evidence packet the filing needs, drawing from records already on the case.
5. Share the draft with a represented client for their review before it goes anywhere, or move it straight to filing if the case doesn't call for client review first.

## Before you begin

You need records already on the case — documents, exhibits, prior filings — before you can build a new filing from them. If the case has nothing logged yet, add what the filing needs first.

## What happens next

A filing you've drafted stays in the workspace, linked to whatever deadline it responds to, so you can find it again from either the filing workspace or the deadline itself. If you shared it with a client for review, their comments or approval show up on the same draft rather than in a separate copy.
