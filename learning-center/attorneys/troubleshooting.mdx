Most questions here come down to a version that hasn't moved the way you expected, or a list that isn't scoped the way you assumed. The list below covers what attorneys and firm staff run into <span className="kw">most</span>.

<AccordionGroup>
  <Accordion title="A client's progress isn't updating">
    Confirm you're looking at the assignment they're actually working through — a client can have more than one assignment for the same module if it was assigned twice. Progress is recorded per assignment, so completing lessons on one doesn't mark them complete on another.
  </Accordion>
  <Accordion title="I assigned a newer version but the client is still on the old lesson list">
    That's expected. Assigning pins the version you were looking at when you made the assignment — republishing a module doesn't move an existing assignment forward. If you want the client to see the newer version, assign it again; the earlier assignment stays as it was.
  </Accordion>
  <Accordion title="I don't see a way to write or edit module content">
    That's not a door open to firms. The catalog is a fixed set of content shared across every workspace — what you control is which module you assign, not what's written in it.
  </Accordion>
  <Accordion title="The assignment list shows more than what I made">
    There's no filter yet for assignments made by you specifically. The list shows every assignment in your workspace, so check the client and case named on each row to find the ones you're looking for.
  </Accordion>
  <Accordion title="I don't see any suggested modules on a case">
    Suggestions only appear once something on the case's record matches a topic a module addresses. If the case hasn't reached that point yet, the list stays empty — that's a fact about the case's current record, not a missing feature.
  </Accordion>
  <Accordion title="A citation in an assigned module looks outdated">
    The text shown for a citation resolves each time the lesson is opened, so it should reflect the current version of that law regardless of when the module was assigned. If something still looks wrong, note the exact citation and contact support rather than assuming the assignment itself is stale.
  </Accordion>
</AccordionGroup>

## Still stuck

If none of the above accounts for what you're seeing, contact [support@fairstandard.com](mailto:support@fairstandard.com) with the client's name, the case if one applies, and a description of what you expected to see. Support can look at the assignment record directly rather than guessing from a description alone.
