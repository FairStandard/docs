The Learning Center holds one catalog of process modules, shared across every workspace on Vero. You don't write the content — you <span className="kw">assign</span> it, to a client, tied to a case if you want one attached. This page covers what that catalog gives you and where the edges of it are.

## How it works

A module is a short guide to one part of the process, broken into lessons a client reads in order. Modules belong to a practice area, and many are written for one state, so a module built for a Texas case and one built for a California case can describe the same phase differently, because the underlying law differs. When a lesson cites a specific law, the text shown is resolved at the time it's read, not fixed at publish time.

Assigning a module to a client pins the exact version that exists at that moment. If a newer version gets published later, the assignment you already made doesn't move to it — the client's lesson list stays exactly as it was the day you assigned it. If you want them to see the newer version, you assign it as a separate assignment.

An assignment doesn't have to be tied to a case. You can assign general education to a client before a case is opened, or alongside one — `case_id` is optional on the assignment itself.

Modules can also connect to what's already on a case. If a case has findings a module addresses, that module shows up as a suggestion for that case — a pointer, not an action taken on your behalf. Nothing is assigned automatically; you decide whether to act on a suggestion.

You don't author or edit module content from here. Publishing new module versions isn't a door open to firms — the catalog is the same fixed set of content for every workspace, and what you control is which of it you hand to a client, not what's in it.

## What you can do here

- **Browse the catalog.** See every current module, filtered by practice area and jurisdiction.
- **Assign a module to a client.** Pick a module, a client, and optionally a case.
- **Check a client's progress.** See which lessons in an assigned module they've completed.
- **Check suggested modules for a case.** See which modules match what's already been found on that case.

## Who sees what

The catalog itself is identical for every workspace — there's no separate content library per firm. Assignments and progress belong to your workspace: a colleague at your firm can see and act on the same assignment record you made, but nothing crosses a workspace boundary into another firm's clients. There's no personal "assigned by me" view yet — the list of assignments you pull back isn't narrowed to only the ones you made yourself.

<Note>
  Vero explains legal process. It does not give legal advice.
</Note>
