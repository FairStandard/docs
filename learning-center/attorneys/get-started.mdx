Getting comfortable with the Learning Center takes a few minutes once you know the shape of it: one shared catalog, and your own record of who you've <span className="kw">assigned</span> what. This guide walks you through browsing, assigning, and checking progress.

## What you'll learn

- How to browse the module catalog by practice area and jurisdiction
- How to assign a module to a client, with or without a case attached
- How to check a client's progress on an assigned module
- How to check whether a case has any suggested modules
- What a workspace-wide assignment list shows, and what it doesn't narrow down to

## Before you begin

You need at least one client set up in Vero. A case isn't required to assign a module — it's optional on the assignment itself.

### Step 1: Open the Learning Center

From the sidebar, select **Learning Center**.

### Step 2: Browse the catalog

Select **Browse modules** to see every current module. Narrow the list by practice area, and by state if the module is written for a specific jurisdiction.

### Step 3: Assign a module

Open a module and select **Assign**. Choose the client, and a case if this assignment belongs to one. The version you assign is the one you're looking at — it's pinned to that assignment from this point forward.

### Step 4: Confirm the assignment

Select **Assigned modules** and find the client's new assignment in the list. It shows the module, the version pinned, and the case it's tied to, if any.

### Step 5: Check the client's progress

Open the assignment and select **Progress** to see which lessons the client has marked complete. An empty progress list means they haven't started yet, not that anything failed.

### Step 6: Check a case's suggested modules

From a case, select **Suggested modules** to see which modules match findings already on that case. A suggestion sits there until you decide whether to assign it — nothing happens on its own.

## Tips

- The **Assigned modules** list can show every assignment in your workspace, not just the ones you made — check the case and client on each row rather than assuming the list is yours alone.
- A module's citations are resolved live, so a client reading an assigned module always sees the current text of a law it references, even though the lesson list itself is fixed to the version you assigned.

<Note>
  Vero explains legal process. It does not give legal advice.
</Note>
