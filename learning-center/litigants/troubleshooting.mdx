Most questions about the Learning Center come down to a module that hasn't been assigned yet, or a <span className="kw">suggestion</span> list that's empty because your case hasn't matched anything yet. The list below covers what people run into most.

<AccordionGroup>
  <Accordion title="I don't see anything assigned to me">
    An empty assignments list is normal if nothing has been assigned to your case yet. You can still browse the full catalog without waiting for an assignment — select **Browse modules** to see everything available.
  </Accordion>
  <Accordion title="I don't see any suggested modules">
    Suggestions only appear once something on your case record matches a topic a module addresses. If your case hasn't reached that point yet, the list stays empty — that's a fact about your case's current record, not a missing feature.
  </Accordion>
  <Accordion title="A module I was reading changed on me">
    A module assigned to you never changes — the version you were assigned stays fixed. If you're browsing the open catalog instead of an assignment, you're always reading the current version, and a newer version can replace it if one gets published. Check whether you're viewing an assignment or the open catalog to tell which case applies.
  </Accordion>
  <Accordion title="Marking a lesson complete didn't seem to do anything">
    Check **Your progress** on the module — a completed lesson stays marked even if the page doesn't visibly change right away. Marking the same lesson complete again is safe; it won't create a duplicate or an error.
  </Accordion>
  <Accordion title="A citation in a lesson looks outdated">
    The text shown for a citation is resolved each time you open the lesson, so it should reflect the current version of that law. If something still looks wrong, note the exact citation and contact support rather than assuming the module itself is out of date.
  </Accordion>
</AccordionGroup>

## Still stuck

If none of the above accounts for what you're seeing, contact [support@fairstandard.com](mailto:support@fairstandard.com) with your case name and a description of what you expected to see. Support can look at the case record directly rather than guessing from a description alone.

</Note>
