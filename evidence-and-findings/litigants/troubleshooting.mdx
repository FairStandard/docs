Most <span className="kw">problems</span> here come down to a record that has not finished processing yet, or a capability your case has not been set up with. The list below covers the ones people run into most.

<AccordionGroup>
  <Accordion title="A record I added is not showing up in a finding">
    Vero needs time to read and connect a record after it is added; most records are processed within a few minutes. If it has been longer than that, confirm the record shows up in the Records Index at all — if it does not, the upload did not complete and you should add it again.
  </Accordion>
  <Accordion title="I do not see patterns or discovery on my case">
    Pattern analysis and the discovery checklist depend on what your case has been set up with. If either one is missing from Case Detail, your case has not been enabled for that capability yet — that is a fact about your case's setup, not an error.
  </Accordion>
  <Accordion title="A call recording has the wrong speaker labels">
    Open the recording and correct the labels yourself — see [Confirm who is speaking in a recording](/evidence-and-findings/litigants/confirm-who-is-speaking-in-a-recording). Vero keeps learning from corrections, so accuracy improves as more recordings are confirmed.
  </Accordion>
  <Accordion title="My discovery checklist has not changed even though I received something">
    A discovery item only updates when it is logged against the specific request it answers. If you received something outside the normal exchange — by mail or in person — add it as a record and note which request it responds to, so it can be matched to the right item.
  </Accordion>
  <Accordion title="My report does not include a record I just added">
    A report reflects your case at the moment you generated it. Generate a new report to include anything added afterward — an existing report does not update on its own.
  </Accordion>
  <Accordion title="A finding does not seem right">
    Open the records the finding lists as its source and check them yourself — a finding is only as good as the records it drew from, and seeing the source is exactly how you catch it if something is misread. Flag it for review so it gets a closer look.
  </Accordion>
</AccordionGroup>

## Still stuck

If none of the above accounts for what you're seeing, contact [support@fairstandard.com](mailto:support@fairstandard.com) with your case name and a description of what you expected to see. Support can look at the case record directly rather than guessing from a description alone.
