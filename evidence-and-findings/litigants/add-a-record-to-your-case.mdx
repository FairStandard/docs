A <span className="kw">record</span> can be anything that shows what happened — a note you write yourself, a photo, a voice memo, an exported set of messages, or a call recording. Adding one takes the same few steps no matter which kind it is.

## Before you begin

You do not need to know why a record matters before you add it. A short note is optional, and you can always add one later.

1. From Case Detail, select **Add a record**.
2. Choose the kind of record you are adding — note, photo, voice memo, message export, call recording, or document.
3. Upload the file, or write your note directly if you are not attaching a file.
4. Add a short note if you want to flag why it matters. This step is optional.
5. Select **Save**.

The record appears on your case right away, tagged with the date and type. Vero reads it, connects it to the events and other records it relates to, and includes it in any finding it belongs in.

## What happens next

If you're represented, your attorney sees the record as soon as you add it — there is no separate step to send it to them. If you're self-represented, the record is yours to work from, and it is still there if you hire an attorney later; nothing you have added is lost by adding representation.

A record you add today can change a finding that already exists, or create a new one. If that happens, the finding shows every record it draws from, including the one you just added, so the connection is never a surprise.
