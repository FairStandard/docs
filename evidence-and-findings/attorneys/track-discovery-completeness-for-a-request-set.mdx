Discovery is the formal process where each side must produce specific documents and records to the other. Closing a <span className="kw">gap</span> in that exchange starts with knowing exactly where one exists, per request, not just a general sense that something is missing.

1. **Open the discovery checklist on Case Detail.** It lists every request set on the case.
2. **Select a request set.** Often a Request for Production, or "RFP," shown with its court label and code.
3. **Review each item's status.** Produced, outstanding, or objected — check the status before assuming a missing item is simply late; an objection is a different situation with a different next step than silence.
4. **Update an item's status when something changes.** Log what came in against the specific request it answers, including anything received outside the normal exchange, so the checklist reflects what actually happened rather than what should have happened by now.
5. **Flag a gap for follow-up.** An item still outstanding past its due date is worth flagging so it gets tracked rather than lost inside a longer list.

## Before you begin

Discovery completeness is an Advanced-tier capability enabled per case. If the checklist doesn't appear on a case, the case hasn't been enabled for it.

## What happens next

The checklist reflects the actual state of discovery as it's logged, not a prediction of what a court will accept or require. Whether an objection is valid, or what to file over a genuinely missing item, is a judgment call this checklist doesn't make for you.
