Getting comfortable with the Marketplace takes a few minutes. This guide walks you through <span className="kw">browsing</span> the directory, filtering it down to what you need, and sending your first consultation request.

## What you'll learn

- How to browse the Marketplace directory
- How to filter listings by specialty, jurisdiction, and service type
- How to open a listing and read a provider's profile
- How to send a consultation request
- How to check whether a request has been accepted or declined

## Before you begin

You don't need a case or an account to browse the directory — it's open to anyone. You will need a way for a provider to identify who's reaching out, since a consultation request carries a message and a way to reach you back. Nothing you do while browsing changes anything on your case; reading a listing is a private, read-only look at what a provider has published.

### Step 1: Open the Marketplace

From the navigation, select **Marketplace**.

### Step 2: Filter the directory

Narrow the list by specialty, jurisdiction, and service type. Leave any filter blank to see a broader set of listings.

### Step 3: Open a listing

Select a listing to read the provider's profile: their headline, biography, and the specialties, jurisdictions, and service types they've published.

### Step 4: Send a consultation request

Select **Request a consultation**, write a short message about what you need, and submit it. The request goes into that provider's queue — nobody else sees it.

### Step 5: Check your request status

Return to the listing to see whether your request is still queued, has been accepted, or was declined. There's no fixed time limit for a decision, and nothing about checking the status changes it.

## Tips

- If a filter comes back empty, try a broader specialty or drop the jurisdiction filter — filtering matches an exact category, not the words in a provider's biography.
- Write enough in your message that the provider can tell whether they're a fit before they decide.
- You can send a request to more than one listing at once. Each request is private to the provider it went to, and sending a second one does not cancel the first.
- If a request is accepted, the connection happens outside the Marketplace for now — Vero keeps the record, but arranging a call or a meeting is something you and the provider work out directly.
