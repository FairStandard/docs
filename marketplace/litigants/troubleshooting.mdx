Most questions about the Marketplace come down to a filter that's too narrow, or a request that's still waiting on a <span className="kw">response</span>. The list below covers what people run into most.

<AccordionGroup>
  <Accordion title="My filters return no listings">
    Filtering matches an exact category, not the words inside a biography. Try a broader specialty, drop the jurisdiction filter, or try a related service type. An empty result usually means the category was too narrow, not that nobody is listed.
  </Accordion>
  <Accordion title="I don't see a provider I know is on Vero">
    Only active listings show up in the directory. A provider who hasn't published a listing, or whose listing isn't currently active, won't appear no matter how you filter — that's a fact about their listing, not a search problem on your end.
  </Accordion>
  <Accordion title="I haven't heard back on my consultation request">
    A request sits queued until the provider decides. There's no set time limit for a decision, and Vero doesn't send reminders on your behalf. If it's been a while, sending a request to another listing is always an option — it doesn't cancel or affect the first one.
  </Accordion>
  <Accordion title="My request was declined — what now?">
    A declined request stays visible as declined; nothing further happens automatically. You're free to send a request to a different listing that matches what you need.
  </Accordion>
  <Accordion title="My request was accepted — why don't I see them on my case?">
    Vero records that the request was accepted, but it doesn't yet add the provider to your case or open a message thread automatically — that connection isn't built yet. Arrange next steps with the provider directly, the way you would after any other consultation.
  </Accordion>
</AccordionGroup>

## Still stuck

If none of the above accounts for what you're seeing, contact [support@fairstandard.com](mailto:support@fairstandard.com) with the listing name and a description of what you expected to see.
