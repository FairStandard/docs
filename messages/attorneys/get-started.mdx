Finding your way around Messages takes a few minutes once you know it's scoped to your whole <span className="kw">caseload</span>, not one case at a time. This guide walks you through your inbox, sending a message, attaching a record, leaving a firm-internal note, and setting your notification preferences.

## What you'll learn

- How your inbox rolls up threads across every case you're on
- How to message a client and keep the thread organized by topic
- How to attach a record from a case to a message
- How to leave a note only your firm sees
- How to set your notification preferences per case
- Where the cooperation picture shows up, if a case has it turned on

## Before you begin

You need at least one case assigned to you before there's a thread to see. If you haven't been added to a case yet, ask whoever manages your firm's client roster to add you first.

### Step 1: Open your inbox

From the sidebar, select **Messages**. You'll see threads from every case you're on, across every organization you belong to, each tagged with the case and firm it belongs to.

### Step 2: Start or open a thread

Select a case from your inbox, then **New thread** if you're starting a new conversation, or an existing thread if you're continuing one. Give a new thread a short subject — the document, deadline, or question it's about — so it stays easy to find later.

### Step 3: Write and send your message

Type your message and select **Send**. Something like `"Can we go over the exhibit list before Thursday?"` sends the same way any message does, and the client is notified according to their own preferences.

### Step 4: Attach a record

If your message is about a document already on the case, select the attachment option and choose the record from the case instead of uploading it again. The client opens the same record you have, in the same context.

### Step 5: Leave a firm-internal note

If you need to flag something for a colleague without putting it in front of the client, select the internal note option on the thread instead of sending a message. The client never sees it; it sits alongside the thread for anyone else at your firm on the case.

### Step 6: Set your notification preferences

Go to your notification settings and choose email, an in-app notice, or both for each case. Preferences are set per case, so a busy matter can have both channels on while a quiet one stays to in-app only.

## Tips

- Give each thread a subject specific enough to find later across a full caseload — "exhibit list, Lopez" is easier to locate than "question."
- Check a case's cooperation picture from its Messages screen if you're deciding whether a slow response is part of a pattern worth raising.
