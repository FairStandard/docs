A message to a client starts from your inbox, not from the case you happen to have open — so switching between matters during the day never means hunting for the right thread. This walks you through finding the right case and sending a <span className="kw">thread</span>-organized message, with a record attached if you need one.

## Before you begin

You need to be assigned to the client's case before there's a thread to send into. If you aren't on the case yet, ask whoever manages your firm's client roster to add you first.

1. From the sidebar, select **Messages**.
2. Find the client's case in your inbox — each row is tagged with the case and organization it belongs to, so you can tell it apart from a similarly named matter at another firm.
3. Select **New thread** for a new conversation, or an existing thread to continue one.
4. If starting a new thread, give it a short subject — the document, deadline, or question it's about.
5. Write your message in the composer.
6. If your message is about a document already on the case, select the attachment option and choose the record from the case instead of uploading it again.
7. Select **Send**.

## What happens next

The client is notified according to their own preferences — by email, an in-app notice, or both. Your message stays in the thread you sent it in, so a later reply from either of you lands in the same place instead of starting a disconnected conversation. A colleague at your firm on the same case sees the thread too, and can add a firm-internal note on it that the client never sees.

If you attached a record, the client opens the same file you have on the case. There's no separate copy for either of you to keep track of, and any note you added to the record on the case still sits with the original.
